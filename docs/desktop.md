# 桌面端使用

AIHouse 桌面端提供系统托盘/任务栏图标和可视化面板，让你不用开终端也能看 Agent 状态。

---

## 启动桌面端

确保后端已启动：

```bash
aihouse start
```

然后启动桌面端：

```bash
cd aihouse/desktop
npm run tauri dev
```

---

## 系统托盘图标

启动后，在系统托盘（Mac 菜单栏 / Windows 任务栏）会出现 AIHouse 图标：

```
🟢 AIHouse
```

图标颜色代表整体运行状态：

| 颜色 | 含义 | 说明 |
|------|------|------|
| 🟢 绿色 | 一切正常 | 所有 Agent 正常运行 |
| 🔵 蓝色 | 全部空闲 | 所有 Agent 空闲 |
| 🟡 黄色 | 注意 | 有 Agent 卡住或警告 |
| 🔴 红色 | 告警 | 有 Agent 任务失败 |

鼠标悬停在图标上会显示简要状态，比如：

```
🟢 所有 Agent 正常 · 2 个运行中 · 1 个空闲
```

### 面板操作

| 操作 | 效果 |
|------|------|
| 点击 Agent 行 | 查看任务详情 |
| 点击"刷新" | 立即执行一次全量检查 |
| 点击"历史" | 查看历史任务记录 |
| 点击"设置" | 打开设置页面 |
| 拖拽标题栏 | 移动面板位置（仅桌面端） |
| 拖拽窗口边缘 | 调整面板大小（仅桌面端） |

## 右键菜单

在托盘图标上右键（Mac）/ 左键（Windows）弹出菜单：

| 菜单项 | 作用 |
|--------|------|
| 打开面板 | 显示/隐藏主面板 |
| 设置 | 打开设置页面 |
| 退出 | 关闭桌面端（不影响后端） |
