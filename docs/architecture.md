# 架构说明

AIHouse 采用前后端分离架构：Python 后端负责监控和数据存储，Tauri 桌面端负责展示。

---

## 核心组件

### 后端（Python）

| 组件 | 文件 | 职责 |
|------|------|------|
| CLI | `cli.py` | 命令行入口，守护进程管理 |
| 配置 | `config.py` | 读写 YAML 配置，检测 Agent |
| 数据模型 | `core/models.py` | AgentTask / AgentStatus 定义 |
| 存储 | `core/storage.py` | SQLite 读写，历史查询 |
| 适配器 | `core/adapter.py` | Agent 适配器接口 |
| 调度器 | `core/scheduler.py` | 定时轮询，异常检测 |
| 分析器 | `core/analyzer.py` | 卡住检测，趋势分析 |
| 通知器 | `core/notifier.py` | 多渠道通知推送 |
| API 服务 | `server.py` | Flask REST API |

### 桌面端（Tauri + Svelte）

| 组件 | 文件 | 职责 |
|------|------|------|
| 主面板 | `App.svelte` | Agent 状态总览 |
| 任务详情 | `TaskDetail.svelte` | 单个任务查看 |
| 历史记录 | `History.svelte` | 历史任务列表 |
| 设置 | `Settings.svelte` | 应用配置 |
| 托盘 | `main.rs` | 系统托盘 + 窗口管理 |

### 适配器

每个 Agent 一个适配器文件，放在 `adapters/` 目录下：

| 适配器 | 监控方式 |
|--------|---------|
| `generic.py` | 进程 + 文件变化（兜底方案） |
| `claude_code.py` | 日志文件 + 进程 |
| `cursor.py` | 日志文件 + 进程 |
| `codex.py` | 进程监控 |
| `opencode.py` | 进程监控 |
| `hermes.py` | 会话数据库 |

## 数据流

```
定时轮询（每 10 秒）
  │
  ▼
适配器获取 Agent 状态
  │
  ▼
状态存入 SQLite → 分析引擎检查异常
  │                    │
  ▼                    ▼
API 响应 ← 桌面端读取    有异常 → 通知器 → 微信推送
```

---

## 数据模型

### AgentTask（任务记录）

| 字段 | 类型 | 说明 |
|------|------|------|
| agent_name | str | Agent 名称 |
| agent_type | str | Agent 类型标识 |
| task_id | str | 任务唯一 ID |
| description | str | 任务描述 |
| status | TaskStatus | 运行中/完成/失败/卡住 |
| started_at | datetime | 开始时间 |
| duration | float | 耗时（秒） |
| files_changed | list[str] | 修改的文件 |
| estimated_cost | float | 预估费用 |

### AgentStatus（Agent 状态）

| 字段 | 类型 | 说明 |
|------|------|------|
| activity | AgentActivity | 活跃/空闲/异常/未运行 |
| current_task | AgentTask | 当前任务 |
| pid | int | 进程 ID |
| tasks_today | int | 今日完成任务数 |
| total_cost_today | float | 今日总费用 |
