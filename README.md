# AIHouse

> 监控你的 AI Agent 在干什么。
>
> 一个开源的桌面应用，监控你所有 AI 编码 Agent 的任务状态。
> 任务跑完了没、卡住了没、成功了没、花了多少钱——瞟一眼就知道。

## 快速安装

```bash
pip install aihouse
aihouse init
aihouse start
aihouse status
```

> 详细步骤请看[快速开始](docs/getting-started.md)。
